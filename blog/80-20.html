Docker

Building an image:

docker build --no-cache --platform linux/amd64 -f path/to/Dockerfile -t image_name:tag --build-arg ARG_NAME=ARG_VALUE /path/to/context

Pushing image to a registry (image name must include registry url):

docker push image_name:tag

Check local images:

docker images

Check images on a registry (ghcr):

curl -H "Authorization: Bearer YOUR_TOKEN" https://api.github.com/users/USERNAME/packages?package_type=container
